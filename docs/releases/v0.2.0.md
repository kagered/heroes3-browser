# Heroes III Browser — v0.2.0

The first public source release of the browser launcher, built around VCMI 1.6.5 and the original Heroes III single-player experience.

**Play:** https://heroes-iii-browser.pages.dev/

## Highlights

- Russian and English with shared local saves.
- Desktop and automatic touch controls, including an iPad rendering profile.
- Save ZIP export/import and separate custom-map collection transfers.
- Original scenario-menu integration for RoE, AB and SoD `.h3m` maps.
- Clear loading stages, verified resource caching, targeted repair and bounded retries.
- Cache management, browser checks, bilingual Help and GitHub feedback drafts.
- Clean source package, pinned engine bootstrap, static publication tools and automated checks.

## Validation

The pre-release automated audit passed 18 groups, including save/map round trips, cache isolation, failure recovery, lifecycle and touch logic, UI state, and all 442 resources in the hosted dataset. The maintainer also confirmed both final manual scenarios: transferring and reloading a real game across computer/iPad and recovering from an interrupted download.

The public test suite uses synthetic fixtures and browser API substitutes; it does not replace an actual game/device run. See `docs/QA.md` for the distinction.

## Known limits

Multiplayer, HotA, WoG and HD Mod are not included. Campaigns are not fully tested. Browser storage is local, not a cloud backup; memory and performance depend on the device. Map collections are limited to 64 maps / 64 MiB (8 MiB per map), and save transfers to 32 MiB per operation.

## Source package

Original game data, personal saves/maps, credentials and prebuilt engine binaries are excluded. To build for publication, follow `docs/BUILD.md` using your own compatible game files. Ordinary players can use the website directly.
